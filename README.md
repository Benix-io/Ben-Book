# ⚡ Ben Book

> A fast, modern snippet manager and floating code companion built natively for Android (API 34, 35, and 36).

---

## ✨ Features

* **🎨 Dynamic Material 3 Themes:** Switch between Dark Pitch, Green Dark, Blue Dark, and Light mode on the fly.
* **⚡ Floating Notification Bubble:** Capture code and quick notes over any active application without context-switching.
* **🔍 Global Instant Search:** Filter across topics, entries, and code snippets in real time.
* **🌈 Real-time Syntax Highlighting:** Visual syntax tokenizer for clean code presentation.
* **🔄 Synchronized Backups:** Seamless export and import via `.sync` proprietary JSON backups.
* **🚀 Native Performance:** 100% pure Java architecture optimized for modern Android system insets and back navigation.

---

## 🛠 Tech Stack

* **Platform:** Android (API 34–36)
* **Language:** Pure Java
* **UI/UX:** Material Design 3 (M3)
* **Package:** `com.systsync`
* **Developer:** Ben ([@Benix-io](https://github.com/Benix-io))
